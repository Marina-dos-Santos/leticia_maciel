# 🌿 Site Profissional – Psicóloga Letícia Maciel
Site institucional desenvolvido para a psicóloga clínica Letícia Maciel, com foco em acolhimento, clareza e facilidade de contato para novos pacientes.
🔗 **Acesse:** [psileticiamaciel.com.br](https://psileticiamaciel.com.br)

## 🎯 Objetivo
Criar uma presença digital que transmita a proposta da psicoterapia (escuta, acolhimento e respeito à singularidade de cada pessoa) e facilite o agendamento de atendimentos por WhatsApp.

## ✨ Funcionalidades
- Landing page de uma página com navegação por seções
- Seções: Início, Sobre mim, Abordagem, Atendimento e Contato
- Botão de agendamento com mensagem pré-preenchida no WhatsApp
- Ícones SVG personalizados para as áreas de atuação
- Layout responsivo para celular, tablet e desktop

## 🛠️ Tecnologias
- HTML5 semântico
- CSS3 
- JavaScript
